# 1000year · 천년의신화 런처

천년의신화 V1.070KR용 Windows 런처입니다. 게임 파일은 포함하지 않습니다.

## 실행

`MythLauncher.exe`를 실행하고 `MMyth.exe`가 있는 게임 폴더를 선택합니다. EXE 안에 호환 DLL, 패치 레시피와 업데이트 설치 도구가 들어 있습니다.

- **1280×720 내부 해상도 (16:9)**: 전장 영역 1152×720. 자원 아이콘과 수치 및 하단 설명 텍스트를 중앙 정렬합니다. 새 설치의 기본 선택입니다.
- **1024×768 내부 해상도 (넓은 전장)**: 실제 전장 영역을 512×480에서 896×768로 확장합니다. 유닛과 타일은 원래 픽셀 크기를 유지하고 HUD는 오른쪽 아래로 이동합니다.
- **1024×768 화면 확대**: 기존 640×480 시야를 크게 표시합니다.
- **640×480 원본 해상도** 및 전체 화면(화면 비율 유지)도 선택할 수 있습니다.
- 메뉴·브리핑은 원래 해상도를 유지하며 전투 진입 시 내부 해상도가 전환됩니다. 전투 중 팝업은 원래 크기로 표시됩니다.
- 시작 시 GitHub 정식 릴리스에서 새 런처를 자동 다운로드·검증·설치하고 재시작합니다. 설정에서 끌 수 있으며 인터넷 오류는 게임 실행을 막지 않습니다.

원본 `MMyth.exe`는 변경하지 않습니다. V1.070KR 해시와 패치 전후 바이트를 검증한 뒤 `MMyth.Wide.exe`, `MMyth.HD.exe` 또는 `MMyth.Portable.exe`를 생성합니다. 구형 설치 경로 대신 현재 폴더에서 파일을 읽고 시작 영상은 건너뜁니다. 최초 적용 전 `ddraw.dll`과 `ddraw.ini`를 백업하며 런처의 ‘원래 그래픽 복원’으로 복구할 수 있습니다. 설정과 로그는 `%LOCALAPPDATA%/1000year/`에 저장합니다.

## 빌드·업데이트 배포

Windows의 .NET Framework 4.x 컴파일러를 사용하므로 별도 SDK 없이 빌드할 수 있습니다.

```powershell
./scripts/build.ps1
./tests/Run-Tests.ps1
# 원본 게임이 있는 개발 환경의 추가 검사
./tests/Run-Tests.ps1 -GameExe '게임폴더/MMyth.exe'
```

결과는 `dist/`에 생성됩니다. `src/Core.cs` 버전과 동일한 `vX.Y.Z` 태그를 push하면 GitHub Actions가 검사 후 EXE, ZIP, SHA256을 Releases에 게시합니다. 자동 업데이트는 ZIP과 파일별 SHA256을 검증하고 설치 준비 확인, 기존 버전 백업, 실패 시 롤백을 수행합니다. 게임 파일과 저장 게임은 업데이트 목록에 포함하지 않습니다. 0.1.0 런처의 업데이트 패키지 형식을 유지합니다.

## 해상도 구현과 검증 범위

다른 프로젝트(아마게돈·태조왕건)의 업데이트 구현과 아마게돈 해상도 분석에서 표면 크기, 버퍼 pitch, 지형 캐시, 안개, HUD, 클릭 판정, 미니맵 투영을 참고했습니다. 패치 주소는 이 게임을 별도로 분석했습니다.

실제 Windows에서 메뉴/백제 첫 전투 진입, 단일 선택, 드래그 선택, 확장 영역으로 우클릭 이동, 미니맵 카메라 이동, 초기 메뉴 복귀, 시험 복사본 저장·불러오기를 검사했습니다. x86 에뮬레이션으로 확장 버퍼 복사와 경계, HUD 좌표, 마우스 좌표 변환을 검사했고, 업데이트 설치·손상 거부·실패 롤백도 검사했습니다.

모든 시나리오, 장시간 전투, 멀티플레이 동기화와 모든 DPI/모니터 조합까지 검증한 것은 아닙니다. 지형 캐시는 안전한 전체 다시 그리기를 사용하므로 저사양 환경에서는 확대 모드보다 부하가 커질 수 있습니다. 내부 구현과 재생성 절차는 [analysis/RESOLUTION.md](analysis/RESOLUTION.md)를 참고하세요.
