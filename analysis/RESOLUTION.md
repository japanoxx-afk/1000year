새 섹션에만 hook/immutable mask/지형 버퍼를 둔다. 기존 코드와 데이터를 일괄 치환하지 않는다. 난수 함수를 추가 호출하지 않으며 시뮬레이션 업데이트 주기를 변경하지 않는다. 전체 캐시 redraw는 단순하고 경계 검증이 쉬우나 저사양 성능 최적화 여지가 있다.

## 재현

개발용 Python 의존성: pefile, capstone, keystone-engine, unicorn. 배포 런처에는 Python이 필요 없다.

```text
python scripts/generate_hd.py --source PATH/TO/MMyth.exe --output compat/hd.json --exe PATH/TO/TEST/MMyth.HD.exe
python tests/test_hd.py PATH/TO/MMyth.exe
python tests/test_native.py
```

`generate_hd.py`는 고정 원본 해시를 확인하고 PE 헤더 여백/섹션 경계를 검사한다. 원본 파일을 배포하지 않고 패치 데이터만 생성한다. 게임 실행용 EXE 출력은 명시적으로 --exe를 지정해야 한다.

## 확인 범위와 남은 장기 검증

- 런타임 ReadProcessMemory: 모드 4, 화면 1024×768×8, 지형 표면 896×768, world rect (0,0,895,767).
- 메뉴 복귀: 모드 2, 화면 640×480×8 확인.
- 백제 첫 전투: 단일 선택, 드래그 다중 선택, 확장된 우측 영역에 우클릭 이동, 미니맵 카메라 이동, Escape 메뉴와 초기 메뉴 복귀. 시험 복사본의 빈 슬롯에 저장하고 불러온 뒤 미니맵/전장 조작 확인. 미탐험 영역으로 카메라 이동 시 확장 영역까지 안개 유지 확인.
- x86 실행 검사: 실제 지형 복사 함수의 896 source stride→1024 destination pitch, HUD 128열 유지와 앞뒤 sentinel, 공통 HUD 좌표, 미니맵 원점, 배경 hit test 역변환.
- C# 원본/패치 해시 검증 및 변조 거부, 업데이트 패키지 설치/백업/사용자 파일 보존/손상 거부/파일 잠금 발생 시 rollback.

전체 종족/시나리오, 지도 끝에서의 모든 건물·마법, 장시간 전투, 멀티플레이 동기화, 모든 DPI 및 전체 화면 환경은 아직 포괄 검증하지 않았다. 화면에 더 많은 지형이 보이는 것과 유닛 탐험 반경 확대는 별개다. 전투 팝업은 원본 크기/위치를 유지한다.

## 0.3.1 · 오른쪽 HUD 세로 중앙 배치

HUD의 480px 높이 배경을 y=(H-480)/2에 배치한다. 720p에서는 y=120으로 이전 y=240보다 120px 위에 위치한다. 공통 버튼/목록/초상화 좌표와 낮밤 표시, 미니맵 원점을 같은 DY로 변경한다. 화면 하단 자원 막대와 설명 텍스트는 화면 하단 기준을 유지한다.

- 0046C546: 배경 BltFast의 y 인자를 새 DY로 설정한다.
- 0046C247: 미니맵을 배경 표면에 그릴 때만 x를 DX만큼 빼고 y를 UP만큼 더한다. 기존 그리기의 H-480 역변환을 상쇄한 뒤 공유 원점을 복구한다.
- 00468140: 배경 투명 픽셀 hit test의 x와 y를 모두 역변환한다.
- 0049D900: 변경된 공유 원점을 사용하는 실제 미니맵 클릭 함수를 실행하여 지도 좌표 변환과 이전 위치 거부를 검사한다.
- 0048B870~0048BAD8: 자원 렌더러 전체를 원본 바이트로 복원한다.


## 0.3.2 · 위치 변경 롤백

중앙 배치 변경을 취소한다. 오른쪽 HUD는 DX=W-640, DY=H-480으로 화면 오른쪽 아래에 고정하고, 미니맵 배경 그리기 및 투명 픽셀 판정의 추가 y 보정을 제거한다. 자원 렌더러는 원본을 유지하고 하단 설명의 중앙 정렬 후크도 제거하여 원래 x=50으로 복원한다. 16:9 화면/전장 버퍼와 해상도에 필요한 오른쪽·하단 기준 보정은 유지한다.


## 0.3.4 · 하단 빨간 막대 보정

0048B810의 DirectDraw BltFast 호출에서 y는 H-12로 보정됐으나 x=6이 남아 있었다. 0048B866의 push/call을 후크하여 x=DX+6으로 전달한다. 원본 막대 길이와 값 계산은 유지한다. 실제 함수를 x86 에뮬레이터에서 실행하여 표면, x/y, 플래그와 호출 스택을 검증한다.


## 0.4.0 · 자원 정렬 / 일꾼 상태 / 전체 선택

`scripts/game_features.py`가 원본 해시로 검증된 주소에만 후크를 설치한다. 심볼은 레시피 `Features`에 기록한다.

- 자원 렌더러 0048B870의 아이콘/글리프 폭과 4개 수치를 합산하여 우측 4px 여백을 유지한다.
- 유닛 배열 007CA6E8, stride 2308, 1..1199. 등록 테이블 00A79620, HP +9C, 소유자 +76, 표시/탑승 +324, 분류 플래그 +1D8. 이동 유닛 bit1, 전투 bit4, 건물 bit2, 영웅 bit20000. 일꾼은 이동 유닛 중 전투·건물 제외.
- 휴식 판정: 현재 행동 +290=1, 대기 명령 +388=1, 예약 수 +3A0=0, +61C=0, 이동 플래그 +74=0 및 현재/목표 타일 일치. 다른 플레이어·죽음·숨김 제외.
- 전투 입력 0046DFF0에서 VK_BE/VK_C0/VK_TAB의 상승 에지를 처리한다. 기존 키 배열 0078C928 사용. 채팅 00B9022C, 원본 상태/조합키 가드 적용.
- native selection은 20개를 유지한다. 전체 그룹의 세대 포함 핸들을 별도 1200-entry 배열에 저장하고 추가 유닛의 선택 표시를 켠다. 수동 선택/해제에서 확장 그룹을 정리한다. 매 프레임 소유권·생존·세대·탑승 상태를 검증하고 앞쪽 native 슬롯을 보충한다.
- 그룹 명령 호출 지점 0046ED15에서만 00435040을 감싸 20개씩 원본 패킷을 생성한다. 시스템/글로벌 명령이나 개별 유닛 명령은 복제하지 않는다.
- 원본 송신 대기열은 5개 제한이다. 0042C490 앞에 추가 FIFO(256 packets)를 두고 여유가 생길 때 원본 큐로 전달한다. 원본 패킷 구조와 시뮬레이션을 변경하지 않는다. 전투 초기화에서 핸들/대기열 상태를 버린다.
- 0046C332 뒤에 원본 한국어 폰트로 `쉬는 일꾼 : N`을 그린다. 기존 툴팁 상태는 변경하지 않는다.
- `tests/test_features.py`에서 분류/입력/표시/정리/세대 검사와 실제 원본 명령 생성기를 실행하며 1,199개 유닛의 모든 핸들이 순서대로 전달됨을 검증한다.
- 이번 실제 화면 자동 검증은 사용자 Escape 중단으로 수행하지 못했다. 멀티플레이, 모든 특수 마법과 장시간 대규모 전투는 별도 검증 대상이다.
