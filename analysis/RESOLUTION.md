# 내부 해상도 조사 — 2026-11-14

## 현재 판정

1024×768 **출력 확대**는 실제 전투와 입력 검사 통과. **내부 시야 확대는 실패한 프로토타입이며 미완료**. 배포 런처의 선택지에 포함하지 않는다. 게임이 부팅된다는 사실만으로 고해상도 지원 완료로 판단하지 않는다.

지원 실행 파일 SHA256: `1b70b78e8ec040697fced744cbc5f0d2a7ff3477cce35fce3185200f031ceabf`.

## 실제 시험

별도 `test-game` 복사본에서 프로토타입 `hd-preview.json`을 적용했다. 원본 파일은 변경하지 않았다.

- 런타임 모드 4, 화면 1024×768×8을 ReadProcessMemory로 확인.
- 전장 사각형 (0,0,895,767)을 확인.
- 메뉴가 원래 크기로 왼쪽 위에 남고 시나리오 선택에 다음 페이지가 노출됨.
- 전투 진입 성공. 그러나 512×480 지형 캐시, 고정 HUD와 미니맵 배치가 남아 지형 누락·분할 표시 발생.
- 이 프로토타입은 사용 가능한 HD 패치가 아니다. 일반 런처의 모드 범위 검사에서 내부 모드 요청을 거부한다.

출력 확대 실행본은 런타임 모드 2, 640×480×8, 전장 (0,0,511,479)을 확인했다. cnc-ddraw의 출력은 1024×768이고 adjmouse=true로 보정한다. 백제 1장 전투에서 태자군 단일 선택, 여러 유닛 드래그 선택, 우클릭 이동을 확인했다. `evidence/1024-unit-selection.jpg` 참조.

## 내부 시야 확장에 필요한 후속 작업

아마게돈 해상도 작업에서 고려한 항목을 이 엔진에 다시 매핑해야 한다.

1. 메뉴·브리핑과 실제 전투의 모드 전환 분리. 화면 전환마다 표면 해제/재생성 및 실패 복구.
2. 지형 캐시 512×480을 전장 크기에 맞게 확장·재배치. 모든 참조·행 간격·복사 길이 확인. 단순 상수 일괄 변경 금지.
3. 타일·안개·효과 순회, 더티 사각형, 스크롤 캐시의 이동 복사, 스프라이트 클리핑 확장.
4. 카메라 원점/중앙/지도 가장자리 제한. 작은 지도, 음수 좌표, 지도 끝 타일 접근 검증.
5. HUD·초상화·자원 수치·버튼·툴팁·클릭 판정을 함께 재배치. 고정 그림 자산 여백 처리.
6. 미니맵 위치/화면 범위 사각형/클릭 좌표, 월드 좌표 투영을 같은 기준으로 수정.
7. 드래그 시작/중간/놓기 경계, 스크롤 가장자리, 건물 배치, 공격·마법 대상 좌표 확인.
8. 저장/불러오기·전체 종족·네트워크 동기화 및 장시간 플레이 확인. 렌더링 변경으로 시뮬레이션/난수 호출 횟수를 바꾸지 않기.

현재는 추가 버퍼와 각 렌더링 경로를 검증하지 못했으므로 후속 작업을 완료했다고 표기하지 않는다.
