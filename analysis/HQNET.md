# HQ넷 로비 재현 — 클라이언트 분석 메모 (V1.070KR, 원본 SHA256 1b70b78e…ceabf)

원래 HQ넷 서버는 폐쇄되었고 서버 프로그램·문서도 없다. 아래는 원본 `MMyth.exe`의 네트워크 코드에서 읽은 사실이다.
주소는 원본 실행 파일 기준.

## 1. 접속 대상

| 채널 | 호스트 (문자열 주소) | 포트 | 소켓 생성 | 객체 |
|---|---|---|---|---|
| 로비(로그인·방) | `hqteam.hqteam.net` (`0x4E1DF8`, 20바이트 칸) | TCP 6112 (`push 0x17E0` @ `0x49E435`) | `0x49E37E` | `0xF6F060` 계열, `ecx` 전달 |
| 채팅 | `chat.hqteam.net` (`0x4E1ECC`, 20바이트 칸) | TCP 6112 (`push 0x17E0` @ `0x49F218`) | `0x49F1F0` | 같은 객체의 두 번째 소켓(+0x76C4) |
| 전투 명령 | 소켓을 직접 만들지 않음 (다른 채널에서 넘겨받음, 미확인) | — | — | `0xD44220` (모듈 `0x4917A0..0x491D80`) |

- DNS 실패 시 로비는 하드코딩 IP `211.233.83.20`(`0x4E1E0C`)으로 접속한다.
- `[obj+0xD8]`/`[obj+0xDC]`: 사용자 지정 서버 주소 문자열 경로가 있다(`0x4A22A4`). `0xB8DD3C`와 `0x4E9AFC` 비교로 분기.
- 전투 중 명령 전송: `0xCED8DC == 1`(HQ넷 대전)이면 TCP 모듈 `0xD44220`(`0x486920` → `0x491CC0`/`0x491A80`),
  아니면 DirectPlay(`0xD37D00`, `0x4B4xxx`). 즉 **HQ넷 대전의 게임 데이터는 TCP로 오간다** → 서버 중계로 공유기 문제 없이 연결 가능.

## 2. 로비·채팅 프레임 (`0x49EFD0` 인코더, `0x49F030`/`0x49F120` 디코더)

```
u16 LE  total = 3 + len(payload)      (3 < total <= 10000, 버퍼 4096)
u8      xor  = payload[0] ^ payload[1] ^ ... ^ payload[n-1]
bytes   payload                        payload[0] = opcode (signed byte)
```
- 체크섬이 틀리면 그 길이만큼 버린다.
- 송신 버퍼 4096바이트(`+0x1388`, 길이 `+0x238C`), 수신 버퍼 4096바이트(`+0x388`, 길이 `+0x2388`).

## 3. 접속 직후 첫 패킷 (`0x4A2271` 이후)

```
payload = 00 0D <ver_hi> <ver_lo>      ver = [0x4DEC80] 의 하위 16비트 (게임 버전)
```

## 5. 전투 TCP 모듈 `0xD44220`

- 8바이트 머리(+4에 u16 길이로 보임, `0x491CE6`), 최대 메시지 0xA0 미만(`0x486C98`), 버퍼 0x2000.
- 소켓은 `+0x254`. 이 값을 채우는 코드는 아직 찾지 못했다(다음 작업).

## 6. 서버 쪽 방침 (계획)

- 라크무·삼국지천명2와 같은 구조: Python 표준 라이브러리 서버, NAS `game-servers/1000year-live/`, Portainer 스택.
- 공유기가 30000~30999만 전달하므로 런처 패치 레시피에서 호스트 문자열을 NAS 주소로, 포트 6112를 30000번대로 바꾼다
  (두 호스트 칸 모두 20바이트 — `akansas.synology.me` 19자 + NUL 이 정확히 들어간다. 더 긴 주소는 새 섹션 문자열을 가리키게 한다).
- 결과는 `data/matches.json`(라크무/삼국지천명2와 같은 모양)으로 남겨 RTS ARENA 드롭박스에 추가.
